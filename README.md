## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/shamshuddin678/django-ice-cream-website.git
````

2. Move into the project folder

```bash
cd django-ice-cream-website
```

3. Create Virtual Environment

```bash
python -m venv virtual
```

4. Activate Virtual Environment

```bash
virtual\Scripts\activate
```

5. Install Django

```bash
pip install django
```

6. Run Migrations

```bash
python manage.py migrate
```

7. Start Server

```bash
python manage.py runserver
```

8. Open Browser

```text
http://127.0.0.1:8000/
```
